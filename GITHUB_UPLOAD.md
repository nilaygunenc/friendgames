# GitHub Repository

FriendGames source repository:

- Repository: https://github.com/nilaygunenc/friendgames
- Main branch: `main`

## Get the project

```bash
git clone https://github.com/nilaygunenc/friendgames.git
cd friendgames
```

## Run the mobile app

```bash
cd mobile
pnpm install
pnpm run web
```

The mobile MVP runs locally without a backend. Optional local environment files and build outputs are excluded by `.gitignore`.
